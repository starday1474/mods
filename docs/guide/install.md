# RPG 모드팩 설치 가이드 (윈도우)

> 초안입니다. 모드팩이 완성되면 최종 정리합니다.

처음 한 번만 설정하면, 그 뒤로는 게임을 켤 때마다 모드팩이 **자동으로 최신 버전으로 업데이트**됩니다.

## 1. Prism Launcher 설치

1. 브라우저에서 `prismlauncher.org`에 접속해 **Download** → **Windows** → 설치 파일(Setup)을 받아 실행합니다.
2. 처음 실행하면 언어 선택 화면이 나옵니다. **한국어**를 고르고 **다음**을 누릅니다.
3. Java 설정 화면이 나오면 **자동으로 Java 다운로드**(Auto-download Java)를 켜 둔 채로 넘어갑니다. 이 모드팩은 Java 21을 씁니다.

## 2. 마이크로소프트 계정 로그인

1. 오른쪽 위 **계정** → **계정 관리** → **Microsoft 추가**를 누릅니다.
2. 화면에 나온 링크와 코드로 로그인합니다. 마인크래프트 Java 에디션을 산 계정이어야 합니다.

## 3. 모드팩 가져오기

1. 받은 `RPG-modpack.zip` 파일을 준비합니다 (압축을 풀지 마세요).
2. Prism 왼쪽 위 **인스턴스 추가** → 왼쪽 목록의 **가져오기** → **찾아보기**로 zip 파일을 고르고 **확인**을 누릅니다.
3. 목록에 **RPG 모드팩**이 생깁니다.

## 4. 처음 실행

1. **RPG 모드팩**을 두 번 누릅니다.
2. 작은 창이 뜨며 모드를 내려받습니다. 처음에는 몇 분 걸립니다. 다 받으면 게임이 켜집니다.
3. 게임 언어는 한국어, 한글 패치는 켜진 상태로 시작합니다.

이후 모드팩이 바뀌면, 게임을 켤 때 같은 창이 잠깐 떴다가 바뀐 것만 받습니다.

## 5. 메모리 설정

기본은 **6GB(6144MB)** 입니다. 참가하는 사람은 그대로 두면 됩니다.

**월드를 여는 사람**은 8GB로 올립니다.

1. **RPG 모드팩**을 오른쪽 클릭 → **편집** → **설정** → **Java** 탭
2. **최대 메모리 할당**을 `8192`로 바꿉니다.
3. 렉이나 튕김이 있으면 `10240`(10GB)까지 올려 봅니다. RAM 16GB PC에서는 그 이상 올리지 않습니다.

## 6. 월드 미리 생성 (월드를 여는 사람, 처음 한 번)

던전과 구조물이 많아서, 처음 가는 지역을 만들 때 렉이 생깁니다. 첫 플레이 전에 미리 만들어 둡니다.

1. 싱글플레이로 새 월드를 만들 때 **치트 허용: 켬**으로 만듭니다.
2. 게임에 들어가서 채팅창(`T`)에 차례로 입력합니다.
   - `/chunky radius 2500`
   - `/chunky start`
3. 다 될 때까지 기다립니다. 진행률이 채팅에 나옵니다. PC 성능에 따라 몇십 분에서 한 시간 넘게 걸립니다.

## 7. 설정 프리셋

| 프리셋 | 대상 | 바꿀 것 (옵션 → 비디오 설정) |
|---|---|---|
| 저사양 | 사양이 낮은 PC | 렌더 거리 6~8, 입자 최소, 엔티티 거리 50% |
| 기본 | 대부분 | 처음 상태 그대로 (렌더 거리 10, 시뮬레이션 거리 6) |
| 영상 촬영 | 촬영할 때 | 쉐이더 켜기, 렌더 거리 늘리기 |

영상 촬영은 월드를 여는 PC가 아닌 다른 사람 PC에서 하는 것을 권장합니다.

### 쉐이더 켜기

옵션 → 비디오 설정 → **쉐이더 팩** → 원하는 쉐이더 팩을 고르고 **쉐이더 켜기**를 누릅니다.

## 8. 자주 생기는 문제

| 증상 | 해결 |
|---|---|
| 모드 다운로드 창에서 오류 | 인터넷 연결을 확인하고 다시 실행합니다. 계속되면 관리자에게 오류 문구를 보내 주세요. |
| 게임이 켜지다가 꺼짐 | Prism에서 **RPG 모드팩** → **로그 보기**를 열고 내용을 관리자에게 보내 주세요. |
| 렉이 심함 | 7번의 저사양 프리셋을 쓰고, 쉐이더가 꺼져 있는지 확인합니다. |
| 메모리 부족으로 튕김 | 5번에서 메모리를 올립니다 (참가자 8GB까지). |
