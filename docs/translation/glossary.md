# 번역 용어집

우리 모드와 다른 모드의 한국어 용어를 통일하기 위한 목록입니다. 번역할 때 여기 있는 표기를 그대로 씁니다. 새 용어를 정하면 이 표에 추가합니다.

## 번역 원칙

- **AI 번역 후 검수**합니다.
- 아이템·블록·툴팁: 정확성과 용어 통일이 우선입니다.
- 스토리·퀘스트·설정글·여신 대사: 자연스럽게 다듬습니다.
- 다른 사람이 만든 한글 패치는 이 저장소에 넣지 않습니다 (공개 저장소).
- 번역 파일 위치: `pack/resourcepacks/rpg-korean/assets/<modid>/lang/ko_kr.json`
- 현황: `docs/translation/coverage.md` (`python3 tools/fetch_jars.py pack .cache/jars` 후 `python3 tools/lang_report.py .cache/jars pack/resourcepacks/rpg-korean docs/translation/coverage.md`)
- CurseForge에서 받는 모드(Savage Ender Dragon, FTB Quests 등)는 다운로드 링크가 없어 현황표에 빠집니다. 따로 확인합니다.
