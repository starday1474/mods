# 여신의 질의 — 질문과 점수표 (초안)

> 지난 기록입니다. 0.3.0부터 여신의 질의는 없어지고 캐릭터 만들기(무기 카드 선택과 별 분배)로 바뀌었습니다. 현재 동작은 `creation-cards.md`와 `admin/modpack.md`를 보세요.

이 문서는 여신의 질의에 들어가는 질문·선택지와, 각 선택지를 고르면 점수가 어디로 가는지 정리한 것입니다.
플레이어에게는 숫자도 직업 이름도 보이지 않습니다. 여기 적힌 숫자는 검토용입니다.

- 데이터 파일: `mod/src/main/resources/data/goddessrpg/inquiry/`
  - `stage1.json` — 1단계 (직업군)
  - `stage2/vanguard.json` — 2단계 (전위 하위 유형)
  - `stage3/vanguard.json` — 3단계 (전위 재능·적성)
- 번역: `mod/src/main/resources/assets/goddessrpg/lang/ko_kr.json`, `en_us.json`
  - 키 형식: `goddessrpg.inquiry.<단계>.<질문 id>` (질문), `...<질문 id>.a1`~`a3` (선택지)
- 코드를 고치지 않고 JSON만 고치면 질문·선택지·점수를 바꿀 수 있습니다.
- 지금은 전위만 2·3단계가 있습니다. 후방 딜러·후방 서포터의 2·3단계는 그 직업군을 열 때 추가합니다.

## 계산 방식 요약

- **1단계:** 고른 선택지의 점수를 직업군별로 더하고, 가장 높은 직업군이 됩니다. 동점이면 전위 → 후방 딜러 → 후방 서포터 순으로 앞선 쪽입니다.
- **2단계:** 같은 방식으로 하위 유형 점수를 더합니다. 동점이면 밸런스형 → 탱커형 → 인파이터형 순입니다. 아직 열리지 않은 유형은 후보에서 빠집니다.
- **3단계:** 모든 분야가 별 3개에서 시작합니다. 고른 선택지의 증감을 더한 뒤 1~5개로 자릅니다.
  - 재능 = 시작 숙련도 (별 1~5 → 시작 레벨 0/2/4/6/8)
  - 적성 = 경험치 배율 (별 1~5 → ×0.6/0.8/1.0/1.25/1.5)

## 1단계 — 직업군 (질문 3개)

점수 표기: 전위 / 후방 딜러 / 후방 서포터. 선택지 순서는 일부러 섞었습니다.

### Q1. 무너지는 다리 (`bridge`)
> 무너져 가는 다리 위입니다. 그대 등 뒤에는 아직 건너지 못한 이들이 있고, 건너편에서는 짐승들이 몰려옵니다. 그대는 어디에 서시겠습니까?

| # | 선택지 | 전위 | 딜러 | 서포터 |
|---|---|---|---|---|
| 1 | 다리 한가운데에 버티고 서겠습니다. 짐승들이 저부터 상대하도록. | 2 | | |
| 2 | 다리 끝 높은 바위 위로 올라가, 다가오는 놈들을 멀리서부터 하나씩 쓰러뜨리겠습니다. | | 2 | |
| 3 | 뒤처진 이들의 손을 잡고, 한 사람도 남김없이 함께 건너겠습니다. | | | 2 |

### Q2. 모닥불 곁의 밤 (`campfire`)
> 긴 여정의 밤, 동료들은 모닥불 곁에서 잠들었습니다. 홀로 깨어 있는 그대는 무엇을 하고 계신가요?

| # | 선택지 | 전위 | 딜러 | 서포터 |
|---|---|---|---|---|
| 1 | 숲 너머를 살피며, 내일 가장 먼저 쓰러뜨려야 할 것이 무엇인지 헤아립니다. | 1 | 2 | |
| 2 | 모닥불 곁을 떠도는 작은 빛들에게 속삭여, 잠든 이들의 꿈을 지켜 달라 부탁합니다. | | 1 | 2 |
| 3 | 검을 무릎 위에 올려 두고, 누구보다 먼저 일어설 수 있도록 어둠을 지켜봅니다. | 2 | | 1 |

### Q3. 여신이 내어 줄 힘 (`gift`)
> 제가 그대에게 한 가지 힘을 내어 드린다면, 그 힘이 어떤 모습이기를 바라시나요?

| # | 선택지 | 전위 | 딜러 | 서포터 |
|---|---|---|---|---|
| 1 | 쓰러진 이를 다시 일으키는 힘이기를. 곁에 선 누구도 홀로 무너지지 않도록. | 1 | | 2 |
| 2 | 적의 한가운데로 뛰어들어도 꺾이지 않는, 단단한 몸과 팔이기를. | 2 | 1 | |
| 3 | 보이지 않는 곳까지 닿는 힘이기를. 위험이 가까이 오기 전에 끝낼 수 있도록. | | 2 | 1 |

**균형:** 세 직업군 모두 전체 선택지에 걸린 점수 합이 8점으로 같습니다. 한 직업군 쪽 답만 고르면 6점으로 그 직업군이 됩니다.
지금은 전위만 열려 있어서 실제로는 누구나 전위가 됩니다. 다른 직업군이 열리면 이 점수표를 그대로 쓸 수 있습니다.

## 2단계 — 전위 하위 유형 (질문 3개)

점수 표기: 밸런스형 / 탱커형 / 인파이터형.

### Q1. 거대한 짐승 (`beast`)
> 거대한 짐승이 그대 앞을 가로막았습니다. 그대의 손에는 무엇이 들려 있습니까?

| # | 선택지 | 밸런스 | 탱커 | 인파이터 |
|---|---|---|---|---|
| 1 | 한 손엔 검, 다른 손엔 방패를. 받아 내고, 틈이 보이면 베겠습니다. | 2 | | |
| 2 | 제 몸을 다 가릴 만큼 커다란 방패를. 그 무엇도 이 뒤로는 넘어가지 못합니다. | | 2 | |
| 3 | 양손으로 겨우 드는 무거운 칼을. 한 번만 제대로 닿으면 끝입니다. | | | 2 |

### Q2. 위험에 빠진 동료 (`ally`)
> 싸움이 길어지고, 동료 한 사람이 위험에 빠졌습니다. 그대는 어떻게 하시겠습니까?

| # | 선택지 | 밸런스 | 탱커 | 인파이터 |
|---|---|---|---|---|
| 1 | 적을 크게 도발해 그 눈길을 제게로 돌리겠습니다. 다치는 것은 저 하나로 족합니다. | | 2 | 1 |
| 2 | 침착하게 동료 곁으로 다가가 적의 공격을 받아 넘기며, 반격할 틈을 찾겠습니다. | 2 | 1 | |
| 3 | 동료를 노리는 놈에게 곧장 뛰어들어, 쓰러질 때까지 몰아붙이겠습니다. | 1 | | 2 |

### Q3. 싸움이 남긴 흔적 (`scars`)
> 싸움이 끝난 뒤, 그대의 몸과 무기에 남은 흔적을 들여다봅니다. 무엇이 보이기를 바라시나요?

| # | 선택지 | 밸런스 | 탱커 | 인파이터 |
|---|---|---|---|---|
| 1 | 상처투성이가 된 제 몸이요. 그래도 마지막까지 서 있던 것은 저였습니다. | | 1 | 2 |
| 2 | 조금 무뎌진 칼날과 흠집 난 방패요. 공격도 방어도 제 몫을 다했다는 증거겠지요. | 2 | | 1 |
| 3 | 온통 움푹 팬 방패요. 그만큼 많은 것을 막아 냈다는 뜻이니까요. | 1 | 2 | |

**균형:** 세 유형 모두 점수 합 8점. 지금은 밸런스형만 열려 있어서, 탱커·인파이터 쪽으로 점수가 몰려도 결과는 밸런스형입니다.

## 3단계 — 전위 재능·적성 (질문 4개)

표기: 재능(검술/방어술), 적성(검술/방어술). 빈칸은 0, 시작은 모두 별 3개.
앞의 두 질문은 주로 **재능**(타고난 출발선), 뒤의 두 질문은 주로 **적성**(자라는 속도)을 움직입니다.
"늦게 시작하지만 잘 자란다"와 "빨리 시작하지만 덜 자란다"는 재능과 적성을 맞바꾸는 선택지입니다.

### Q1. 어린 시절 (`childhood`)
> 그대가 아직 어렸을 적을 떠올려 보세요. 무엇이 가장 먼저 그대의 몸에 익었나요?

| # | 선택지 | 재능 검 | 재능 방어 | 적성 검 | 적성 방어 |
|---|---|---|---|---|---|
| 1 | 나뭇가지를 검 삼아 휘두르던 감각이요. 무엇을 쥐든 손에 착 감겼습니다. | +1 | | | |
| 2 | 넘어지고 부딪혀도 툭툭 털고 일어나던 몸이요. 아픔에 쉽게 꺾이지 않았지요. | | +1 | | |
| 3 | 무엇을 하든 남들보다 늦었습니다. 대신 한번 익힌 것은 결코 잊지 않았지요. | -1 | -1 | +1 | +1 |

### Q2. 첫 싸움 (`first_fight`)
> 처음으로 진짜 싸움에 휘말렸던 날, 그대의 몸은 어떻게 움직였나요?

| # | 선택지 | 재능 검 | 재능 방어 | 적성 검 | 적성 방어 |
|---|---|---|---|---|---|
| 1 | 막을 생각은 잊고 손이 먼저 나갔습니다. 정신을 차리니 상대가 쓰러져 있었지요. | +1 | -1 | | |
| 2 | 웅크린 채 끝까지 버텼습니다. 칼을 휘두르진 못했지만, 쓰러지지도 않았습니다. | -1 | +1 | | |
| 3 | 몸이 알아서 움직였습니다. 이상하게도… 그 뒤로 그만큼 잘 싸운 적은 없었지요. | +1 | +1 | -1 | -1 |

### Q3. 배움 (`learning`)
> 그대는 언제 가장 깊이 배우시나요?

| # | 선택지 | 재능 검 | 재능 방어 | 적성 검 | 적성 방어 |
|---|---|---|---|---|---|
| 1 | 같은 동작을 천 번, 만 번 되풀이해서 손끝이 스스로 기억할 때요. | | | +1 | |
| 2 | 몇 번이고 얻어맞으며, 어디로 받아 내야 덜 아픈지 몸이 깨달을 때요. | | | | +1 |
| 3 | 목숨이 걸린 실전에서요. 한 번의 승부가 백 번의 연습보다 많은 것을 가르쳐 줍니다. | | | +1 | +1 |

### Q4. 먼 길의 끝 (`journey_end`)
> 먼 길의 끝에서 마주할 그대 자신은, 어떤 모습이기를 바라시나요?

| # | 선택지 | 재능 검 | 재능 방어 | 적성 검 | 적성 방어 |
|---|---|---|---|---|---|
| 1 | 어떤 강적 앞에서도 망설임 없이 칼을 뽑는 사람이요. 지키는 일은 다른 이에게 맡기겠습니다. | | | +1 | -1 |
| 2 | 칼끝이 무뎌도 괜찮습니다. 등 뒤의 누구도 잃지 않는 사람이고 싶습니다. | | | -1 | +1 |
| 3 | 지금의 저와 크게 다르지 않았으면 합니다. 서두르지 않아도, 그걸로 족하니까요. | | | -1 | -1 |

### 결과 분포

4개 질문 × 3개 선택지 = 81가지 조합을 모두 같은 확률로 골랐다고 할 때의 별 개수 분포입니다 (검술·방어술은 대칭이라 같음).

| 항목 | ★1 | ★2 | ★3 | ★4 | ★5 | ★2~4 비율 |
|---|---|---|---|---|---|---|
| 재능 | 9 | 9 | 27 | 18 | 18 | 약 67% |
| 적성 | 4 | 18 | 26 | 17 | 16 | 약 75% |

- 대부분 별 2~4개가 나오고, 한쪽으로 몰아서 답하면 별 5개나 1개도 나옵니다.
- 예: 검 쪽 답만 고르면 재능 검 ★5 / 방어 ★2, 적성 검 ★5 / 방어 ★2.
- 예: 각 질문의 3번만 고르면 모두 ★3 근처에서 끝납니다 (재능 ★3, 적성 ★3).

## 검토해 주실 점

1. 여신의 말투(존댓말, 따뜻하고 조금 신비로운 느낌)가 원하시는 분위기와 맞는지.
2. 선택지에서 성향이 "어느 정도" 드러나는지. 너무 노골적이거나, 반대로 너무 모호한 선택지가 있는지.
3. 1단계 Q2·Q3의 보조 점수(1점)가 선택지 내용과 어울리는지. 특히 "작은 빛들에게 속삭임 → 서포터 2, 딜러 1"(마법 느낌).
4. 3단계에서 "지금 그대로가 좋다" 선택지가 적성을 깎는 것이 괜찮은지.
5. 영어 문장(`en_us.json`)은 한국어를 옮긴 것이므로 한국어를 먼저 확정해 주세요.
