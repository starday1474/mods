# 동작 라이브러리 목록 (검토용)

전투 클래스별로 만든 애니메이션 57개의 목록입니다. 각 동작은 `mod/anim/`의 원본에서 생성되며, 미리보기 GIF는 갤러리 페이지에서 볼 수 있습니다.

- 게임에서 직접 볼 수 있습니다(스킬·평타에는 아직 연결 전). 채팅창(T)에서 `/goddessrpg anim list`로 이름을 확인하고 `/goddessrpg anim play <이름>`으로 재생, `/goddessrpg anim stop`으로 멈춥니다. 명령어는 치트 허용 또는 OP 2단계가 필요하고, F5 3인칭으로 봐야 합니다. 근접 공격 동작(balanced·tank·infight)은 검(공격 속도 1.6)을 들고 재생해야 원래 속도로 보이며 주변 몬스터를 실제로 때릴 수 있습니다. 시전 동작(궁수·마법사·소환사·힐러·유물사의 스킬 동작)은 무기와 상관없이 일정한 속도로 재생되고 피해를 주지 않습니다. 반복 동작은 움직이거나 `anim stop`을 할 때까지 계속됩니다.
- 표에서 `대체 예정(다듬지 않음)`이라고 적힌 12개는 임시 자리 표시 동작입니다. 다른 모드의 동작으로 바꿔 쓸 예정이니(`vanguard-moveset.md` 참고) 이 동작들로 품질을 판단하지 마세요.
- 미리보기 범례: 오른쪽 검은 막대는 주 손 무기·지팡이입니다(궁수와 유물사에게는 의미 없음, 유물사는 유물 깨우기만 유물). 회색 판은 방패, 왼쪽 막대는 왼손 검 또는 (궁수) 활입니다.
- 길이는 초 단위이고, 반복은 끝나면 처음부터 다시 도는 동작(대기, 채널링 등)인지를 뜻합니다.
