# 레퍼런스 키트 (refkit) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 레퍼런스 영상과 이미지를 모으고, 자르고, 타이밍과 자세를 재고, 우리 동작과 나란히 비교하는 Windows용 Python 명령 도구 `refkit`을 만든다.

**Architecture:**
- `tools/refkit/` 아래에 독립 패키지(`refkit`)를 두고, `pip install -e tools/refkit`로 `refkit` 명령을 설치한다.
- 무거운 일은 외부 프로그램에 맡긴다.
  - ffmpeg: 자르기, 프레임, 합성
  - yt-dlp: 허용된 출처의 영상 받기
  - mpv: 타이밍 표시
  - MediaPipe: 자세 추정
- refkit은 그 앞뒤를 엮는다. 메타데이터는 저장소의 `docs/refs/*.yaml`에 두고, 미디어는 저장소 밖의 로컬 라이브러리에 둔다.

**Tech Stack:** Python 3.11+ (CI는 3.13), PyYAML, numpy, Pillow, ffmpeg, yt-dlp, mpv, mediapipe(선택 extra `pose`), pytest

**Spec:** `docs/superpowers/specs/2026-11-23-reference-kit-design.md`

## Global Constraints

- **운영체제:** Windows가 기본이다(사용자 결정 2026-11-23). 리눅스 CI에서도 테스트가 통과해야 한다.
- **경로:** `pathlib`만 쓴다. 외부 프로그램은 `subprocess.run([...])`처럼 리스트 인자로 호출하고, `shell=True`는 쓰지 않는다. 실행 파일은 `shutil.which`로 찾는다.
- **저장소에는 메타데이터만 둔다.**
  - `docs/refs/<motion>.yaml`에는 링크, 구간, 태그, `take` 메모, 표시 시각, 자세 통계(숫자)만 담는다.
  - 영상, 이미지, 프레임, 랜드마크 원본은 라이브러리에만 둔다.
  - 라이브러리 위치는 환경변수 `REFKIT_LIBRARY`가 있으면 그 값, 없으면 `Path.home() / "refkit-library"`다.
  - 미디어 경로는 `<library>/<motion>/<id>/`이다.
- **출처 정책:** 기본은 링크 모드다. `fetch`는 `tools/refkit/sources.yaml`이 허용한 경우에만 다운로드한다. `import`(로컬 파일)는 항상 허용한다.
- **따라 그리기 금지:** 레퍼런스를 우리 동작 키프레임(`mod/anim/*.json`)으로 내보내는 기능은 만들지 않는다. refkit은 `mod/anim`을 **읽기만** 한다. 자세 추정 결과는 각도와 타이밍 통계로만 남긴다.
- **YAML:** `yaml.safe_load`와 `safe_dump(allow_unicode=True, sort_keys=False)`를 쓴다. 한국어 메모가 그대로 보존되어야 한다.
- **메시지:** 사용자에게 보이는 메시지는 한국어로 쓴다. 외부 프로그램이 없으면 traceback 대신 설치 명령을 보여주고 종료 코드 2로 끝낸다.
- **설치 명령(doctor와 문서에 같은 문구):**
  - `winget install Gyan.FFmpeg`
  - `winget install yt-dlp.yt-dlp`
  - `winget install mpv` (없으면 `winget search mpv`)
  - `pip install -e tools/refkit[pose]`
- **우리 동작의 phase:** `mod/anim/<name>.json`의 `phase = {antic, contact, recovery}`(초)와 `length`를 쓴다.
  - 비교할 때 우리 동작의 "타격 시각"은 `contact`, "끝"은 `length`다.
- **레퍼런스 표시:** `marks = {start, impact, settle}`(초, 클립 기준)이다.
  - 비율: 예비 = (impact − start) / (settle − start), 회복 = (settle − impact) / (settle − start)
  - 우리 동작: 예비 = contact / length, 회복 = (length − contact) / length
- 모든 변경 후 `python3 -m pytest tools/refkit tools/anim`이 통과해야 한다.

## Review Focus

1. **공백과 한글이 들어간 Windows 경로:** 예를 들어 `C:\Users\홍길동\Videos\활 영상.mp4`. import, clip, pose가 깨지지 않아야 한다. (Task 2 테스트: 공백과 한글이 든 임시 경로)
2. **시간 표기 여러 가지:** `62`, `1:02`, `1:02.5`, `0:01:02`를 모두 받는다.
   - end ≤ start는 오류다.
   - end가 영상 길이를 넘으면 영상 길이로 잘라낸다. (Task 1, Task 2 테스트)
3. **같은 레퍼런스를 다시 add:** url과 start가 같으면 중복 추가하지 않고 기존 항목을 갱신한다. 한국어 메모는 왕복 후에도 그대로여야 한다. (Task 1 테스트)
4. **외부 프로그램이나 mediapipe가 없음:** 한국어 안내와 설치 명령을 보여주고 종료 코드 2로 끝난다. traceback이 나오면 안 된다. (Task 2, Task 5 테스트)
5. **사람이 안 잡히는 프레임(가려짐, 화면 밖):** 해당 프레임은 NaN으로 두고 통계에서 제외한다. 잡힌 프레임이 50% 미만이면 경고한다. 사람이 하나도 안 잡히면 통계를 쓰지 않는다. (Task 5 테스트)

### Task 3: 타이밍 표시와 비교: `mark`, `timing`

**Files:**
- Create:
  - `tools/refkit/refkit/{marks,anim}.py`
  - `tools/refkit/refkit/mpv/refkit_marks.lua` (패키지 데이터로 포함)
  - `tools/refkit/tests/test_marks.py`
- Modify: `cli.py`, `pyproject.toml`(package-data)

**Interfaces:**
- Consumes: Task 1의 `store`. Task 2의 `media.clip_ref`, `tools.require`
- Produces:
  - `refkit_marks.lua`
    - mpv 단축키: `1` = start, `2` = impact, `3` = settle, `0` = 표시 지우기
    - 누를 때마다 `script-opts`의 `refkit-out` 파일에 `<label> <time-pos>`를 한 줄 덧붙인다(지우기는 `clear 0`).
    - OSD에 `start 0.533`처럼 표시한다.
  - `marks.parse_marks_file(path: Path) -> dict[str, float]`
    - 각 라벨의 마지막 값을 쓴다. `clear`가 나오면 그 앞의 값은 버린다.
    - 알 수 없는 줄은 무시한다.
  - `marks.validate(m: dict) -> list[str]`: `start < impact < settle`이 아니면 한국어 경고 목록을 반환한다.
  - `marks.run_mpv(clip: Path, out: Path) -> None`
    - 실행 인자: `mpv --loop-file=inf --speed=0.5 --keep-open=yes --script=<lua> --script-opts=refkit-out=<out> <clip>`
  - CLI
    - `mark --motion M --id ID`
      - clip이 없으면 먼저 `clip_ref`를 실행한다.
      - mpv가 끝나면 표시를 읽어 `Ref.marks`에 저장한다.
    - `mark --motion M --id ID --set start=0.2 impact=0.62 settle=1.1`: mpv 없이 직접 입력한다.
  - `anim.load_phase(name: str) -> tuple[float, dict | None]`
    - `repo()/mod/anim/<name>.json`에서 `(length, phase)`를 읽는다.
    - 파일이 없으면 `FileNotFoundError`다. 읽기만 한다.
  - `marks.ratios_ref(m) -> {"windup": float, "recovery": float, "total": float}`
  - `marks.ratios_ours(length, phase) -> 같은 키`

    - 0 nose, 11/12 어깨, 13/14 팔꿈치, 15/16 손목, 23/24 골반, 25/26 무릎, 27/28 발목
  - `analysis.angle(a, b, c) -> np.ndarray`: b를 꼭짓점으로 하는 각도(도). 입력은 `(N, 3)` 배열이며, NaN이 있으면 결과도 NaN이다.
  - `analysis.joint_angles(lm: np.ndarray) -> dict[str, np.ndarray]`
    - `lm`은 `(N, 33, 3)` 월드 좌표이고, 못 잡힌 프레임은 NaN이다.
    - 키
      - `elbow_l`, `elbow_r`, `shoulder_l`, `shoulder_r`(팔과 몸통 사이), `knee_l`, `knee_r`
      - `torso_twist`: 어깨선과 골반선의 수평 각도 차이
      - `torso_lean`: 몸통의 수직 기울기
  - `analysis.speed(lm, joint: int, fps: float) -> np.ndarray`: 프레임 간 이동 속도. 이웃 NaN은 NaN이다.
  - `analysis.suggest_marks(lm, fps, joint=16) -> dict[str, float] | None`
    - 오른손목 속도를 이동평균(5프레임)한 뒤 최대점을 impact로 잡는다.
    - impact 이전에 속도가 최대치의 20% 아래였던 마지막 시각을 start로 잡는다.
    - impact 이후에 20% 아래로 처음 내려간 시각을 settle로 잡는다.
    - 유효 프레임이 부족하면 None이다.
  - `analysis.summarize(lm, fps) -> dict`
    - 결과 예: `{"frames": N, "detected": 0.93, "angles": {name: {"min", "max", "range"}}, "suggested_marks": {...}|None}`
    - 값은 소수점 1자리(각도)와 3자리(시각, 비율)로 반올림한다.
    - 감지율이 0.5 미만이면 `"warning": "사람이 잡힌 프레임이 50% 미만"`을 넣는다.
    - 감지율이 0이면 `angles={}`로 둔다.
  - `runner.MODEL_URL = "https://storage.googleapis.com/mediapipe-models/pose_landmarker/pose_landmarker_full/float16/latest/pose_landmarker_full.task"`
    - 모델은 `<library>/_models/`에 한 번만 받는다.
  - `runner.frames(video: Path) -> Iterator[tuple[float, np.ndarray]]`
    - ffmpeg가 `rawvideo rgb24`를 파이프로 내보낸다. 크기는 `probe`로 얻는다. OpenCV는 쓰지 않는다.
  - `runner.estimate(video: Path) -> tuple[np.ndarray, np.ndarray, float]`

    - 사람이 없으면 해당 프레임은 NaN이다.
    - mediapipe가 없으면 `MissingTool("mediapipe", "pip install -e tools/refkit[pose]")` 예외를 던진다.
  - `overlay.draw(video: Path, lm_img: np.ndarray, out: Path) -> Path`
