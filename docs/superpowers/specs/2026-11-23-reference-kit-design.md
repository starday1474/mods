# 레퍼런스 키트 (refkit) 기획서

- 작성일: 2026-11-23
- 상태: 초안이며 사용자 검토가 필요하다.
- 관련 문서: `docs/design/motion-principles.md` (5장: 모을 곳과 검색어)

## 1. 목적

동작을 만들 때 레퍼런스 영상과 이미지를 **빠르게 모으고, 잘라 보고, 우리 동작과 나란히 비교**하는 일을 자동화한다.

지금 하는 방식은 이렇다.
- 링크를 찾는다.
- 몇 초 구간인지 따로 적는다.
- 영상 플레이어로 느리게 돌려 본다.
- 미리보기 GIF와 눈으로 비교한다.

이 과정을 명령 몇 개로 줄이는 것이 목표다.

하지 않는 것:
- 레퍼런스 동작을 우리 동작 키로 **자동 변환하지 않는다.** 그렇게 하면 프레임 따라 그리기와 같아진다.
- 도구는 **보고, 재고, 비교하는 것까지만** 돕는다. 동작은 사람이 원리를 섞어 새로 만든다.

## 2. 원칙

1. **저장소에는 메타데이터만 둔다.** 링크, 구간, 태그, 메모만 저장소에 남긴다.
   - 다운로드한 영상, 이미지, 잘라낸 클립은 각자 PC의 로컬 라이브러리에만 둔다(gitignore).
   - 다른 사람에게 재배포하지 않는다.
2. **출처별로 정책을 둔다.** 출처 사이트의 이용약관을 지킨다.
   - 기본값은 **링크 모드**다. 링크와 구간만 저장하고, 브랜치에서 그 구간을 바로 여는 링크를 만든다.
   - 다운로드는 허용된 출처에서만 한다. 예를 들면 직접 촬영한 영상, CC 라이선스 자료, CMU 모션캡처 DB처럼 다운로드를 허용하는 곳이다.
   - 사용자가 직접 받아 둔 파일은 **가져오기**(import)로 넣는다.
   - 출처별 허용 여부는 설정 파일 하나에서 관리한다.
3. **가장 좋은 레퍼런스는 직접 찍은 영상이다.** 친구가 휴대폰으로 활 당기는 자세나 휘두르기를 찍은 영상이 그렇다. 권리 문제가 없고, 원하는 각도로 찍을 수 있다. 그래서 키트는 휴대폰 영상 가져오기를 1순위로 지원한다.
4. **분석 결과는 숫자로만 쓴다.** 자세 추정으로 얻는 것은 타이밍 비율과 관절 각도 범위 같은 통계다. 키프레임은 내보내지 않는다. 자세 추정은 실제 사람 영상에만 쓰고, 게임 영상에는 쓰지 않는다.

## 3. 이용할 기존 프로그램

새로 만들기보다 검증된 무료 도구를 엮는다.

| 도구 | 하는 일 | 비고 |
|---|---|---|
| **ffmpeg** | 구간 자르기, 30fps 맞추기, 슬로모션, 프레임 추출, 비교 영상 합성 | 핵심 엔진 |
| **yt-dlp** | 허용된 출처의 영상 받기 | 출처 정책이 허용할 때만 호출 |
| **mpv** | 프레임 단위 재생, 0.25배속, 구간 반복 | 타이밍 표시 도구의 플레이어 |
| **Kinovea** | 스포츠 영상 분석: 프레임 넘기기, 각도 재기, 두 영상 나란히 보기 | 무료, Windows. 수동 분석은 이것으로 충분 |
| **PureRef** | 이미지 보드(자세 사진 모으기) | 무료(후원제) |
| **MediaPipe Pose** | 실제 사람 영상에서 관절 위치 추정 | 선택 기능, Python |
| 우리 `tools/anim/preview.py` | 우리 동작의 미리보기 GIF/PNG | 비교의 반대편 |

**우선 바로 쓸 수 있는 조합:** Kinovea와 PureRef만 설치해도 수동 분석은 지금 바로 할 수 있다. 키트는 그 앞뒤의 반복 작업(모으기, 자르기, 정리, 비교)을 자동화한다.

## 4. 만들 프로그램: `tools/refkit/` (Python 명령줄 도구)

### 4.1 명령

| 명령 | 하는 일 |
|---|---|
| `refkit add <url> --motion archer_charge --start 1:02 --end 1:10 --tags 궁도,당기기 --note "가이 호흡"` | 레퍼런스를 등록한다. 기본은 링크 모드 |
| `refkit import <파일> --motion ...` | 휴대폰 영상이나 받아 둔 파일을 라이브러리로 가져온다 |
| `refkit fetch [--motion ...]` | 출처 정책이 허용하는 항목만 내려받는다 |
| `refkit clip <id>` | 구간을 잘라 30fps로 맞추고, 0.25배속 버전과 프레임 띠 이미지(콘택트 시트)를 만든다 |
| `refkit mark <id>` | mpv로 재생하며 키를 눌러 예비 동작 시작, 타격, 회복 끝 시각을 표시한다 |
| `refkit timing <motion>` | 표시한 구간 비율을 우리 동작의 phase와 `motion-reference.md` 기준에 비교해 표로 보여준다 |
| `refkit compare <motion>` | 레퍼런스 클립과 우리 미리보기를 타격 시각에 맞춰 나란히 붙인 영상을 만든다 |
| `refkit board <motion>` | 썸네일, 메모, 링크, 우리 미리보기를 한 장에 모은 로컬 HTML 보드를 만든다 |
| `refkit pose <id>` (선택) | 실제 사람 영상의 관절 각도 곡선과 요약 통계(허리 비틀기 최대치, 당김 팔꿈치 높이 등)를 뽑는다 |
| `refkit doctor` | ffmpeg, yt-dlp, mpv 설치 여부와 라이브러리 경로를 점검한다 |

### 4.2 데이터

저장소에 들어가는 파일은 `docs/refs/<motion>.yaml`이다. 링크와 메모만 담는다.

```yaml
motion: archer_charge
refs:
  - id: kyudo-01
    kind: video            # video | image | mocap | own
    url: https://...       # own이면 비움
    start: "1:02"
    end: "1:10"
    tags: [궁도, 가이, 호흡]
    take: "만작에서 가슴이 미세하게 부풀었다 가라앉음"
    marks: {anticipation: 0.00, impact: 0.62, recovery_end: 1.10}   # 초, refkit mark 결과
```

로컬에만 두는 것은 라이브러리 폴더다. 기본 위치는 `~/refkit-library/<motion>/<id>/`이고, 원본, 잘라낸 클립, 슬로모션, 프레임 시트, 자세 추정 결과를 담는다.

출처 정책은 `tools/refkit/sources.yaml`에 둔다.

```yaml
default: link        # link | fetch
fetch_allowed:       # 다운로드 허용(약관·라이선스 확인한 곳만)
  - own
  - mocap.cs.cmu.edu
  - "license:cc-by"
```

### 4.3 우리 동작 도구와의 연결

- `refkit timing`은 `mod/anim/<name>.json`의 phase 시각을 읽는다. 레퍼런스 비율과 차이가 크면 "예비 동작이 짧음(레퍼런스 대비 0.6배)"처럼 알려준다.
- `refkit compare`는 `preview.py`로 우리 동작을 렌더한 결과를 그대로 쓴다.
- 결과는 제안까지만 한다. 동작 JSON은 자동으로 수정하지 않는다.

## 5. 실행 환경

- **사용자 PC(Windows 가정)에서 실행한다.** 클라우드 작업 환경에서는 영상 사이트 접속이 막혀 있을 수 있고, 라이브러리도 PC에 있어야 볼 수 있다.
- 설치는 한 번만 한다.
  - `winget install ffmpeg mpv yt-dlp`
  - `pip install -e tools/refkit`
- 자세 추정 기능은 별도 extra로 둔다: `pip install -e tools/refkit[pose]`
- 휴대폰에서 볼 때는 `refkit board` 결과를 보면 된다. 필요하면 링크와 메모만 담은 공유용 페이지로 내보낼 수도 있다. 이 페이지에는 영상 파일을 넣지 않는다.

## 6. 단계별 계획

| 단계 | 내용 | 결과 |
|---|---|---|
| M1 | `add`, `board`, `doctor`, yaml 형식, 출처 정책(링크 모드) | 링크 모음과 보드 |
| M2 | `import`, `fetch`(정책 준수), `clip` | 로컬 클립, 슬로모션, 프레임 시트 |
| M3 | `mark`, `timing` | 타이밍 비율 비교 표 |
| M4 | `compare` | 레퍼런스와 우리 동작을 나란히 붙인 영상 |
| M5 (선택) | `pose` | 실제 사람 영상의 각도와 타이밍 통계 |

각 단계마다 pytest 테스트를 둔다. ffmpeg 호출은 짧은 합성 영상으로 검증한다. 궁수 동작 재작업(Plan 4) 전에 M1~M3까지 끝내는 것이 목표다.

## 7. 위험과 대응

| 위험 | 대응 |
|---|---|
| 사이트 약관 위반, 저작물 재배포 | 기본은 링크 모드, 허용 목록 기반 다운로드, 저장소에는 미디어 금지(검사 스크립트로 막음) |
| 결과가 "따라 그리기"로 흐름 | 키프레임 내보내기 기능을 만들지 않음. 자세 추정은 실제 사람 영상만, 출력은 통계만 |
| 도구 설치가 번거로움 | `refkit doctor`가 빠진 것과 설치 명령을 알려줌 |
| 영상 링크가 사라짐 | yaml에 `take`(무엇을 배웠는지) 메모를 필수로 둠 → 영상이 사라져도 지식은 남음 |

## 8. 사용자 확인 필요

1. 사용하는 PC의 운영체제 (Windows / macOS)
2. 자세 추정(M5)을 넣을지 여부
3. 직접 촬영을 1순위 레퍼런스로 삼는 방식에 동의하는지 (친구에게 촬영을 부탁할 수 있는지)
